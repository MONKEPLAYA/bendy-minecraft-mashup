# Smoke test checklist

1. Install BepInEx (recommended: latest x86 or x64 matching the game) into the Bendy install folder.
2. Copy build/bendy-minecraft-mashup-0.1.0.dll into BepInEx/plugins
3. Start Bendy and verify the plugin logs "Bendy-Minecraft companion plugin loaded." into BepInEx/LogOutput.log
4. Open inventory with `I` and see the hotbar/UI overlay
5. Craft a simple item and place a block
6. Mine a placed block and observe drop
