# bendy-minecraft-mashup

Bendy and the Ink Machine (host) + Minecraft: Java Edition (companion) mashup.

License:
- Code: MIT
- Data/content: CC-BY-SA

This repository contains a small prototype mod that runs inside Bendy (Unity) and exposes a Minecraft-like inventory, crafting, placement and mining system that reads textures from the player's own Minecraft installation at runtime.

Quick status
- Repo created and initial scaffold committed.
- Next steps: build the plugin DLL, install BepInEx into the Bendy game folder, place the DLL under BepInEx/plugins, then launch Bendy to test.
